# Sign Search Convention

Chrome / Brave extension that adds a search panel to [sign.com](https://sign.com). It shows each signer's full name and email instead of just their initials, and tells you who has signed. You can filter by status and by class, and export to CSV.

## Installation

1. Download **[sign-search.zip](https://github.com/studoo-app/sign-search/releases/latest/download/sign-search.zip)** (latest version) and unzip it into a folder you won't move.
2. Open `brave://extensions` (or `chrome://extensions`) and turn on **Developer mode**.
3. Click **Load unpacked** and select the folder that contains `manifest.json`.
4. Reload sign.com. Open the panel with the **🔎 Rechercher** button, or with **Alt + Shift + S**.
