# Sign.com Recherche

Extension Chrome / Brave qui ajoute un panneau de recherche à [sign.com](https://sign.com). Elle affiche le nom complet et l'email de chaque signataire, au lieu des seules initiales, et indique qui a signé. On peut filtrer par statut et par classe, et exporter en CSV.

## Installation

1. Clonez le dépôt, ou téléchargez-le avec **Code → Download ZIP** puis décompressez-le :
   ```
   git clone https://github.com/bfoujols/sign-search.git
   ```
2. Ouvrez `brave://extensions` (ou `chrome://extensions`) et activez le **Mode développeur**.
3. Cliquez sur **Charger l'extension non empaquetée** et choisissez le dossier qui contient `manifest.json`.
4. Rechargez sign.com. Ouvrez ensuite le panneau avec le bouton **🔎 Rechercher**, ou avec **Alt + Maj + S**.
